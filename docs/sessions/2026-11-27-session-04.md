# Session 04 Log (2026-11-27) — Local-first APK, bundled packs

1. Direction change: local project, APK on the RG477V, GitHub = code backup.
2. **Blu Mar Ten "Jungle Jungle" 1989–1999**: free pack (read-me: made for fun, not to be sold, share via blumarten.bandcamp.com; samples are lifted from commercial records, use at own risk). Personal device only: lives in gitignored `local-packs/`.
3. **`tools/build-packs.mjs`** (`npm run packs`): extracts `local-packs/*` (ZIPs or folders) to `packs/<id>/`, decodes WAV in Node (afconvert for AIFF/MP3), runs the app's own classifier, writes `packs/index.json`. 800 samples / 4 packs in ~3 s. Library loads the index at startup (no import, no IndexedDB copy) and fetches WAVs on demand; favourites for built-ins in localStorage.
4. Classifier: Camelot key codes ("8A" → Am), RIFF category, plural folder names, display names drop the key suffix, loops/breaks without a tempo in the name get **bar-fitted tempo** (whole bars; breaks prefer 150–180 BPM) instead of raw transient detection; sub-0.9 s "breaks" become one-shots.
5. **Capacitor 8 Android project** + `MainActivity` native gamepad bridge (works without WebView Gamepad API), `tools/build-apk.sh` (`npm run apk`), service worker disabled inside the app.
